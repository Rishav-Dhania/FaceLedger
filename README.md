# FaceLedger

A React Native Expo starter for an automated student attendance monitoring and analytics system.

## Run locally

```bash
npm install
npm start
```

Then press `a` for Android, `i` for iOS, or `w` for web.

## Validate

```bash
npm run typecheck
npx expo export --platform android
```

The current MVP includes a branded landing screen plus student and faculty workspace previews. The product implementation roadmap is in [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md).
